GeoAI

×
FastAPI · Gemini OCR · AWS

A FastAPI service that takes scanned Russian geological reports — a PDF, or a ZIP/RAR/7z of page images — and returns structured facts for each site. Uploads are hashed, validated and streamed straight to S3, and re-uploading the same file returns the existing document. Processing is queued through SQS FIFO to a separate worker, one job per document, with a dead-letter queue so nothing stays locked.

Pages with a usable text layer are read directly; the rest go to Gemini 2.5 Flash for OCR, ten at a time with retries. Three analysis passes then find the sites, summarize the general chapters and extract JSON per site — every fact cites its page and keeps the original Russian wording. Site coordinates are checked against a snapshot of Kazakhstan's mineral licence blocks with a Shapely STRtree to flag overlaps with existing claims.
