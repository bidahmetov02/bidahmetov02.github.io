Document AI · Live

GeoAI

×

A FastAPI service that takes scanned Russian geological reports — a PDF, or a ZIP/RAR/7z of page images — and returns structured facts for each site. Uploads are hashed, validated and streamed straight to S3, and re-uploading the same file returns the existing document. Processing is queued through SQS FIFO to a separate worker, one job per document, with a dead-letter queue so nothing stays locked.

Pages with a usable text layer are read directly; the rest go to Gemini 2.5 Flash for OCR, ten at a time with retries. Three analysis passes then find the sites, summarize the general chapters and extract JSON per site — every fact cites its page and keeps the original Russian wording. Site coordinates are checked against a snapshot of Kazakhstan's mineral licence blocks with a Shapely STRtree to flag overlaps with existing claims.

Demand forecasting · Live

StockWise

×

Helps a retailer avoid running out of stock or holding too much. Users upload the daily Excel sales and stock reports they export from 1C; a FastAPI backend parses them and stores each user's shops, products, sales and stock separately in Postgres. Every night a batch job refreshes the forecasts, adds up the next 30 days for each SKU and compares it with current stock to flag it as understocked, overstocked or OK — so the React dashboard reads saved recommendations and never waits on the ML service.

Forecasting lives in a separate microservice: one global LightGBM model trained on every user's history pooled together, predicting daily demand for each shop–product pair. Each series is normalized by its own average demand, so small and large sellers share one model fairly. The model retrains weekly on all users' data and trains itself on a fresh deploy. The whole stack runs under Docker Compose on an Oracle VPS, with the host's Caddy as the only public entry point — it serves the app over HTTPS and forwards /api to a backend that isn't reachable from outside.

Document translation · Live

audar

×

Translates .docx files between Kazakh and Russian in place, so the result keeps the original's structure and formatting. The document, headers, footers and footnotes are edited as lxml trees; each paragraph becomes tagged text, with formatting, tabs, breaks and embedded objects as XML tags, and every piece goes to DeepL in one ordered batch. Runs are rebuilt from the formatting saved per tag, and a paragraph whose tags come back broken falls back to plain text in its first run instead of corrupting the file.

A FastAPI backend handles email and password sign-in with rotating JWT refresh tokens in HttpOnly cookies, validates uploads as real .docx files and stores them in a private S3 bucket; downloads are short-lived presigned URLs. Each upload becomes a job on SQS with a dead-letter queue, and a separate worker translates it, skipping finished jobs and retrying only transient errors. Per-document and monthly per-user character limits, plus a global stop that keeps a reserve of DeepL credit, keep translation costs bounded. It runs under Docker Compose on an Oracle VPS behind Caddy.
